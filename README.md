# Измерение скорости скачивания

Нужен Python 3.8 или новее. Сторонних зависимостей нет.

```sh
python3 download_speed.py 'https://example.com/image.jpg'
```

Скрипт выполняет последовательные GET-загрузки по HTTP или HTTPS.
Тело каждого ответа читается до конца блоками по 64 КиБ и не сохраняется на диск.
HTTP-перенаправления обрабатываются автоматически.

Необязательные параметры:

- `--count` — количество загрузок, целое число больше нуля (по умолчанию 10).
- `--timeout` — тайм-аут сетевой операции в секундах, число больше нуля (по умолчанию 30). Это не ограничение на полное время загрузки.
- `--delay` — пауза между загрузками в секундах, ноль или больше (по умолчанию 0). После последней загрузки паузы нет; паузы не входят в замеры.

Для `--timeout` и `--delay` можно указывать дробные секунды через точку.

```sh
python3 download_speed.py 'https://example.com/image.jpg' --count 5 --timeout 10 --delay 0.5
```

В выводе:

- `Average request time` — среднее время одной загрузки в секундах, включая ожидание ответа.
- `Total downloaded` — суммарный размер тел ответов в байтах, без HTTP-заголовков.
- `Download speed` — суммарный объём, делённый на суммарное время загрузок, в МБ/с (`1 MB = 1 000 000` байт).

При ошибке скрипт сообщает номер загрузки,
завершается с ненулевым кодом и не выводит частичную статистику.
